# Customer_Behaviour_Analysis_DA
Analysis of Customer behaviour using Python, PostgreSQL and PowerBI

# Data Analytics Project: End-to-End Pipeline

## Overview
This project demonstrates a complete data analytics workflow from raw data to actionable insights. It includes data loading, exploratory data analysis (EDA), data cleaning, SQL-based analysis using PostgreSQL, and visualization through a Power BI dashboard. The objective is to extract meaningful insights and present them in a clear, business-friendly format.

## Dataset
* The dataset contains structured data relevant to business/customer analysis.
* Includes features such as demographics, transactions, and behavioral patterns.
* Data was imported into Python for preprocessing and further analysis.

## Tools & Technologies
* **Python** (Pandas, NumPy, Matplotlib, Seaborn)
* **PostgreSQL** (SQL queries for data analysis)
* **Power BI** (Interactive dashboard)
* **Jupyter Notebook** (Development environment)

## Project Workflow
### 1. Data Loading
* Imported dataset into Python using Pandas
* Initial inspection of data structure and types

### 2. Exploratory Data Analysis (EDA)
* Summary statistics and distribution analysis
* Identification of trends, patterns, and anomalies
* Visualization using plots and charts

### 3. Data Cleaning
* Handling missing values
* Removing duplicates
* Data type corrections
* Feature transformation (if required)

### 4. SQL Analysis (PostgreSQL)
* Loaded cleaned data into PostgreSQL database
* Wrote SQL queries to:
  * Aggregate key metrics
  * Perform joins and filtering
  * Extract business insights

### 5. Dashboard Creation (Power BI)
* Built an interactive dashboard
* Included KPIs, trends, and filters
* Designed for easy interpretation by non-technical users


## Dashboard
The Power BI dashboard provides:
* Key performance indicators (KPIs)
* Trend analysis over time
* Category-wise comparisons
* Interactive filters for deeper insights


## Results & Insights
* Identified key patterns and trends in the dataset
* Highlighted areas of improvement and opportunity
* Provided data-driven recommendations for decision-making
